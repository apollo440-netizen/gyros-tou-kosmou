# 🌍 Γύρος του Κόσμου

Εκπαιδευτικό παιχνίδι γεωγραφίας στα ελληνικά — σημαίες, χώρες, πρωτεύουσες, διαδραστικός παγκόσμιος χάρτης και εγκυκλοπαίδεια 197 χωρών. Για παιδιά και ενήλικες.

## Εκτέλεση

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build στο dist/
npm run preview  # σερβίρισμα του build
```

Δεν χρειάζεται backend, API κλειδιά ή σύνδεση στο διαδίκτυο μετά το install.

## Λειτουργίες

- **Βρες τη Χώρα** — σημαία → 4 χώρες
- **Βρες την Πρωτεύουσα** — χώρα (+σημαία) → 4 πρωτεύουσες με εύλογους αντιπερισπασμούς
- **Σημαίες** — Μικτό / Σημαία→Χώρα / Χώρα→Σημαία (4 σημαίες)
- **Βρες τη Χώρα στον Χάρτη** — κλικ στη σωστή χώρα στον παγκόσμιο χάρτη
- 3 επίπεδα δυσκολίας (Εύκολο/Μεσαίο/Δύσκολο), 10/20/ατέρμονες ερωτήσεις
- Πόντοι + μπόνους σερί + μπόνους ταχύτητας, πίνακας βαθμολογίας (LocalStorage)
- Εγκυκλοπαίδεια με αναζήτηση χωρίς τόνους και φίλτρα ηπείρων
- Σελίδα χώρας με στατιστικά, γρήγορα στοιχεία και κινούμενο **CountryBall**
- Πλήκτρα 1–4 για απαντήσεις, Enter για επόμενη ερώτηση
- Ηχητικά εφέ WebAudio (χωρίς αρχεία ήχου) με διακόπτη 🔊

### Δεδομένα χωρών

197 κυρίαρχα κράτη σε 6 αρχεία ανά ήπειρο, με ελληνικά ονόματα σε ονομαστική/αιτιατική/γενική (για σωστές προτάσεις), πρωτεύουσες με καθιερωμένα ελληνικά εξωνύμια, στρογγυλεμένους πληθυσμούς («Περίπου …»), νόμισμα, γλώσσες, 2–4 γρήγορα στοιχεία και βαθμίδα δυσκολίας 1–3. Κλειδιά: ISO 3166-1 alpha-2 / alpha-3 / numeric.

### Παραγωγή ερωτήσεων

Η `QuestionStream` κρατά ανακατεμένη ουρά χωρών (χωρίς κοντινές επαναλήψεις) από το pool της δυσκολίας. Αντιπερισπασμοί: πρώτα «παρόμοιες σημαίες» (χειροποίητες ομάδες, π.χ. Ολλανδία/Λουξεμβούργο/Ρωσία) σε μεσαίο/δύσκολο, μετά ίδια ήπειρος, μετά τυχαίοι. Οι πρωτεύουσες-αντιπερισπασμοί προτιμούν την ίδια ήπειρο. Νέοι τύποι ερωτήσεων προστίθενται με ένα νέο `QuestionType` + branch στο `buildQuestion`.

### Χάρτης

`world-atlas` (Natural Earth, 1:50m TopoJSON, φορτώνεται lazy) → GeoJSON με `topojson-client` → μονοπάτια SVG με `d3-geo` (προβολή Natural Earth) → ζουμ/μετακίνηση με `d3-zoom` (ποντίκι και αφή). Η σύνδεση γεωμετρίας↔χώρας γίνεται **μόνο** μέσω ISO numeric κωδικών, ποτέ με ονόματα. Εδάφη/χώρες εκτός dataset εμφανίζονται γκρι και μη διαδραστικά· χώρες χωρίς γεωμετρία (π.χ. Τουβαλού) εξαιρούνται αυτόματα από το παιχνίδι χάρτη.

### CountryBall

Διαδικαστικό React component: κύκλος SVG με `clipPath`, τη σημαία της χώρας ως clipped `<image>`, ακτινική σκίαση, καρτουνίστικα μάτια και CSS animations (αιώρηση, ανοιγόκλεισμα ματιών, ελαφριά κλίση). Καμία ξεχωριστή εικόνα ανά χώρα — μία υλοποίηση για όλες.

### Αποθήκευση

LocalStorage με κλειδιά ανά έκδοση: `geographyGame:scores:v1`, `geographyGame:settings:v1`. Όλες οι αναγνώσεις περνούν από ασφαλές parse με validators και fallbacks — κατεστραμμένα δεδομένα δεν ρίχνουν ποτέ την εφαρμογή. Ονόματα παικτών: μέγιστο 20 χαρακτήρες, καθαρισμός ελέγχων/`<>`.

## Ιδέες για επόμενη έκδοση

- Νέοι τύποι ερωτήσεων (η μηχανή τους υποστηρίζει ήδη): ήπειρος, νόμισμα, «ποια χώρα είναι μεγαλύτερη;», πληθυσμός
- Επιτεύγματα/παράσημα ανά ήπειρο
- Λειτουργία 2 παικτών (εναλλάξ)
- Στατιστικά ανά χώρα (ποιες δυσκολεύουν τον παίκτη)
- Πραγματικά ηχητικά δείγματα στο soundManager (η αρχιτεκτονική είναι έτοιμη)
